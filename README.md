
# 7D — One Connect App

Welcome to 7D! A simple Android app prototype designed to connect users with useful services.

## Features

- 🏠 Home screen
- 💇 Salon services
- 🛒 Grocery shopping demo
- 📅 Booking requests
- 🧭 Explore services
- 🛍️ Cart with quantity and total

## Technology

- Kotlin
- Android Studio
- Jetpack Compose
- Material Design

## Project Status

This is an early-stage prototype for learning and development.

## Setup

1. Download or clone this repository.
2. Extract `7D_Android_App.zip`.
3. Open the extracted Android project in Android Studio.
4. Allow Gradle to sync.
5. Run the app on an Android device or emulator.
